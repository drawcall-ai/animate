# @drawcall/animate

Procedural motion for three.js characters and creatures rigged with [@drawcall/rig](https://www.npmjs.com/package/@drawcall/rig), without animation clips or runtime ML. Bodies stand, walk and look around; your timeline tells them where to walk, look, reach, grab and carry. They can also follow player input or tracked head and hand targets.

Install with `pnpm add @drawcall/animate @drawcall/rig @pmndrs/timeline three`.

The shipped [animate skill](skills/animate/SKILL.md) includes a runnable example, skeletons and authoring patterns. Import bodies, verbs and custom-species helpers from `@drawcall/animate`.
